# Elder test script

The first live test begins only after the Realtime voice path works.

Speak in Hindi or Hinglish for three minutes. Include unfinished-thought pauses of about 0.8, 1.5, and 2.2 seconds. Record interruptions, finalized-turn-to-first-audio latency, name recognition, language switching, warmth, and whether barge-in stops Saathi promptly.

Do not invent results before a live human test is completed.
